Abstract—Reinforcement learning (RL) has been increasingly
applied to network control problems, such as load balancing.
However, existing RL approaches often suffer from lack of interpretability and difficulty in extracting controller equations. In
this paper, we propose the use of Kolmogorov-Arnold Networks
(KAN) for interpretable RL in network control. We employ
a PPO agent with a 1-layer actor KAN model and an MLP
Critic network to learn load balancing policies that maximise
throughput utility, minimize loss as well as delay. Our approach
allows us to extract controller equations from the learned neural
networks, providing insights into the decision-making process.
We evaluate our approach using different reward functions
demonstrating its capability in improving network performance
while providing interpretable policies.

I. I NTRODUCTION
Network providers face increasing complexity and must
support diverse traffic, necessitating agile, autonomous networks to manage tasks like routing and QoS while controlling
costs. This requires new algorithms for decision-making and
control. Existing methods relying on optimization or control
theory require full system knowledge, which is challenging.
Meanwhile, ML approaches, though effective, often lack interpretability—a critical barrier for deployment in sensitive
environments where failures can be costly.
We focus on load balancing over Software-Defined Wide
Area Network (SD-WAN) where traffic flows between origindestination pairs can be distributed across multiple logical paths. We propose an interpretable Deep Reinforcement
Learning approach integrating a Kolmogorov Arnold Network
(KAN) [1] within a Proximal Policy Optimization framework
to obtain load balancing policies which enhance throughput
and reduce packet loss. Our method extracts symbolic policies,
offering both performance and interpretability essential for
network operators. Our source code is available online1 .
A. Related work
Traffic Engineering (TE) optimizes network resource utilization while meeting performance requirements like throughput
and reliability. Traditional mechanisms, such as MPLS-TE [2],
rely heavily on signaling protocols like RSVP-TE [3], which
limits flexibility in dynamic environments. Segment Routing
over IPv6 (SRv6) [4] enhances modern TE by leveraging the
IPv6 stack for flexible, stateless packet forwarding. It uses
1 https://github.com/safeml/sdwan

the Segment Routing Header (SRH) to guide packets along
predetermined paths without requiring complex control protocols like RSVP or LDP, reducing core overhead. Oblivious TE
methods like shortest-path routing often lead to congestion.
Semi-oblivious approaches such as COPE [5] improve link
utilization but face computational overhead and sensitivity to
traffic changes.
Deep Reinforcement Learning (DRL) has shown promise in
optimizing network QoS metrics, with works including [6] for
delay minimization. Most DRL-based TE methods lack interpretability and overlook safety during training and inference,
risking link capacity violations. Constrained approaches like
RCPO [7] offer soft guarantees through Lagrangian methods,
while Control Barrier Functions (CBFs) [8], [9] provide hard
safety assurances. Interpretability is crucial for understanding
model functionality and failures. Methods to achieve interpretability include using intrinsically interpretable models like
decision trees or techniques like model distillation [10]. Recent
work by [11] uses symbolic AI for explanations, while [12]
applied distillation to convert DRL into decision trees.
In contrast, our KAN-based actor maintains interpretability
by design and learns to improve performance by load balancing flows across paths with varying network conditions.
This paper is organized as follows: Section I introduces the
paper and reviews related work, Section II details our approach
of KAN based DRL, Section III presents results, and Section
IV concludes the paper.
II. I NTERPRETABLE R EINFORCEMENT L EARNING
We propose replacing the traditional black-box actor in an
actor-critic agent with a single-layer KAN, as shown in Fig. 1.
This approach leverages the Kolmogorov-Arnold representation theorem, which states that any continuous function can
be expressed using univariate splines. In our implementation,
each state feature feeds into these splines, whose outputs are
summed and passed through another function to produce an
action. This decomposition allows for clear interpretability by
tracing how each input contributes to the decision. Despite its
simplicity, our 1-layer KAN actor matches the performance
of deeper multilayer perceptrons (MLPs). The critic remains
a standard MLP, estimating the state value V (s), and both
components are trained end-to-end using Proximal Policy
Optimization (PPO) [13], [14].

III. E VALUATION
We evaluated our approach using detailed NS-3 packet-level
simulations. The simulation environment and DRL training
parameters are summarized in Table II. CleanRL library for
DRL was used after modifications to implement a KAN-based
actor instead of the default MLP-based one. Our traffic model
employed TCP ON-OFF flows as non-homogeneous Poisson
processes with time-varying arrival rates following a sine-wave
pattern within episodes. The average rate for each episode λ̂
was randomly varied for both inter-episode and intra-episode
variations to simulate dynamic load conditions. Depending on
the episode’s average λ̂, traffic resulted in a sine-like pattern
with randomly chosen phase, troughs between 7–12 Mbps,
and peaks between 17–27 Mbps. Traffic demands resulted in
approx. 0.3 to 1.3 times the combined network capacity, with
background traffic generated via a Poisson process resulting
in 5–8 Mbps. This setup captured realistic network behavior,
where elastic traffic responded to congestion by experiencing
delays and packet losses, prompting TCP flows to back off
until sufficient bandwidth was available.

Count Balancing (FCB). UCMP distributes traffic per flow
using a hash function on flow identifiers (e.g., 5-tuple). FCB
places flow in proportion to MPLS and Internet link capacities,
while counting active flows on each link to maintain this ratio.
CCDFs for throughput utility, packet loss, and delay show that
PPO and PPO-KAN outperformed baselines in most aspects.

cases achieving similar or better throughput utility compared

in cases when there was no-loss. Extracted symbolic policies

IV. C ONCLUSION
We proposed the use of KAN for interpretable RL in load
balancing problems. We showed the advantage of combining
KAN with PPO to learn policies that maximize throughput
utility and minimize loss while being interpretable. We also
showed that for load balancing, we could extract well performing symbolic policies. We believe that our approach can
be applied to other networking problems. Future work includes
evaluating our approach on more complex problems.
